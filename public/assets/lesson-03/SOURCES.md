# 3차시 오디오 출처

아래 WAV 네 파일은 외부 음원이나 생성형 AI를 사용하지 않고, 수업용으로 직접 만든 결정적 절차 합성 음원입니다.

- `rain-soft.wav`: 고정 시드 노이즈와 짧은 빗방울 감쇠음을 합성
- `birds-morning.wav`: 사인파 주파수 변화로 짧은 새 지저귐을 합성
- `wind-low.wav`: 고정 시드 노이즈를 저역 통과시켜 바람 소리를 합성
- `thunder-low.wav`: 고정 시드 노이즈와 감쇠하는 저주파를 겹쳐 천둥을 합성

`scripts/generate_lesson03_audio.py`를 실행하면 항상 같은 파형이 만들어지며, 학생 개인정보나 온라인 서비스는 사용하지 않습니다.
