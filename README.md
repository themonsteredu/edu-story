# EDU STORY

초등 3~4학년 대상 AI+교과 융합 프로그램 **「AI와 함께 만드는 우리 옛이야기 그림책」**의 수업 웹앱입니다.

현재 1~3차시가 구현되어 있으며, 3차시는 **「AI가 이해하는 데이터」**입니다.

## 1차시 운영 방식

- 기본 수업: 교사용 PPT + 종이 학생 활동지
- 선택 수업: 태블릿을 사용할 때만 학생용 웹앱 사용
- 활동지·교수학습 과정안·교사용 답안: `/teacher`에서 교사 비밀번호 `3035`로 접근

홈 첫 화면에는 수업용 PPT와 학생용 웹앱 입구를 함께 두되, 1차시 학생용 웹앱은 선택 기능으로 안내합니다.

## 2차시 운영 방식

- 수업용 PPT로 인물·배경·사건을 안내한 뒤 학생용 웹앱에서 모둠 활동
- 고정 옛이야기 3종 중 하나를 골라 인물·배경 확인, 사건 6개 배열, 장면별 인물·장소·느낌·그릴 모습 기획
- 휴대폰에서는 `앞`·`뒤` 버튼, 태블릿·PC에서는 드래그와 버튼을 함께 지원
- 생성형 AI·외부 API·생성 이미지·SVG 삽화 없이 교사가 검토한 고정 자료만 사용
- 학생 활동지는 긴 글쓰기 없이 ○표·사건 순서·짧은 낱말·간단한 장면 스케치로 구성
- 고정 이야기 읽기 자료는 이야기별 A4 한 장으로 교사 설정에서 제공

## 3차시 운영 방식

- 문자·이미지·소리 카드를 탭으로 분류하고 바로 확인
- 같은 장면에 서로 다른 자료 묶음을 적용해 느낌이 달라지는 까닭 비교
- 2차시에 고른 이야기와 장면을 불러와 문자·이미지·소리 데이터 꾸러미 완성
- 생성형 AI·외부 회원가입·개인정보 입력 없이 실사 사진과 고정 음원만 사용
- 긴 서술형 없이 듣기·고르기·말하기 중심으로 진행

## 구현 기능

- 학생용 1차시 5단계 활동
  - 생활 속 AI 장면 찾기
  - 추천·인식·분류·자동기계로 사례 나누기
  - 작동 설명에서 사용 정보와 결과 찾기
  - 알맞은 칸에 ○표하고 분류 근거를 말로 설명하기
  - 학습 데이터와 정해진 조건·순서의 차이 정리
- 학생용 2차시 5단계 활동
  - 이야기 선택
  - 인물·배경 찾기
  - 사건 카드 6개 순서 배열
  - 여섯 장면의 인물·장소·느낌·그릴 모습을 구체적인 선택지로 기획
  - 학생 선택이 담긴 그림책 기획판 완성·인쇄
- 학생용 3차시 4단계 활동
  - 문자·이미지·소리 데이터 분류
  - 같은 장면의 두 데이터 묶음 비교
  - 2차시에서 기획한 장면 선택
  - 문자·이미지·소리 데이터 꾸러미 완성·인쇄
- 1차시 교사용 웹 프레젠테이션 15장
- 2차시 교사용 웹 프레젠테이션·PPTX 13장
- 3차시 교사용 웹 프레젠테이션·PPTX 13장
- 교사 설정 `/teacher`
  - 교사 화면 잠금
  - PPT·활동지 우선 실행
  - 외부 서비스 없이 진행하는 수업 운영 기준
  - 학생 활동 초기화
- 수업자료
  - PPTX
  - A4 1장 학생 활동지 DOCX
  - 학교 제출용 교수·학습 과정안 DOCX
  - 교사용 답안 DOCX
  - 웹 인쇄·PDF 저장본
- 반응형 UI와 자체 호스팅 S-Core Dream 웹폰트 적용

## 주요 주소

- `/present/1` 교사용 웹 프레젠테이션
- `/lesson/2` 2차시 학생 활동
- `/present/2` 2차시 교사용 웹 프레젠테이션
- `/lesson/3` 3차시 학생 활동
- `/present/3` 3차시 교사용 웹 프레젠테이션
- `/teacher` 교사 설정

## 현재 저장 방식

1~3차시 학생 웹 활동 기록과 교사 로그인 상태는 브라우저 `localStorage`에 기기별로 저장됩니다.

## 교육과정 기준

업로드된 10차시 지도안의 ‘생활 속 AI 찾기’를 유지하고, 학교의 외부 AI 서비스 사용 제한에 맞춰 다음과 같이 재구성했습니다.

- 생활 속에서 AI가 쓰이고 있는 장면 찾아보기
- 추천·인식·분류 기능과 자동기계 구별하기
- 데이터의 특징을 찾는 AI와 정해진 조건·순서로 작동하는 기계 비교하기
- 사용 허가가 확인된 실사 사례를 관찰 자료로 사용하기
