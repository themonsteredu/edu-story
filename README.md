# EDU STORY

초등 3~4학년 대상 AI+교과 융합 프로그램 **「AI와 함께 만드는 우리 옛이야기 그림책」**의 수업 웹앱입니다.

현재 구현 범위는 1차시 **「사람과 AI, 누가 더 잘 볼까?」**입니다.

## 구현 기능

- 학생용 1차시 5단계 활동
  - 생활 속 AI 장면 찾기
  - 같은 문장으로 나의 상상 표현하기
  - 터치·마우스 스케치
  - AI 이미지와 비교하기
  - 사람의 경험·기억과 AI의 학습 데이터 차이 정리
- 교사용 웹 프레젠테이션 15장
- 교사 설정 `/teacher`
  - 비밀번호 `3035`
  - 학생 활동 열기·닫기
  - 외부 AI 이미지 생성 도구 주소 설정
  - 교사 시연 이미지 업로드
  - 학생 활동 초기화
- 수업자료
  - PPTX
  - A4 1장 학생 활동지 DOCX
  - 학교 제출용 교수·학습 과정안 DOCX
  - 교사용 답안 DOCX
  - 웹 인쇄·PDF 저장본
- 반응형 UI와 S-Core Dream 웹폰트 적용

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run check
npm run build
```

## 주요 주소

- `/` 프로그램 홈
- `/lesson/1` 학생 활동
- `/present/1` 교사용 웹 프레젠테이션
- `/teacher` 교사 설정

## 현재 저장 방식

1차시 학생 활동과 교사 설정은 브라우저 `localStorage`에 저장됩니다. 따라서 현재 버전의 공개 상태와 시연 이미지는 기기별로 적용됩니다. 이후 여러 학생 기기를 실시간으로 제어할 때는 Supabase 등 교실 동기화 계층을 연결할 수 있도록 기능을 분리해 두었습니다.

## 교육과정 기준

업로드된 10차시 지도안의 다음 내용을 기준으로 1차시를 구성했습니다.

- 생활 속에서 AI가 쓰이고 있는 장면 찾아보기
- 같은 문장을 듣고 내가 상상한 그림과 AI가 만든 그림 비교하기
- 사람은 경험으로, AI는 데이터로 이해한다는 차이 알아보기
